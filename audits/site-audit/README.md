# Portfolio Site Audit

Generated by `execution/audit_site.mjs`.

## Outputs

- `dashboard.html` - standalone approval dashboard with cleanup findings, link buckets, filters, and UI/UX next-pass notes.
- `audit-results.json` - machine-readable audit data used by the dashboard.
- `google-links-review.html`, `.csv`, `.json` - focused Google resource status report showing public-working, private/auth-required, and broken Google URLs.
- `resource-preservation-manifest.html`, `.csv`, `.json` - preservation-first dashboard that pairs Google URLs with local `Ref Docs` inventory, separates likely offline artifacts from source/index-only files, and keeps missing artifacts visible for future recovery.

## Rerun

From the repo root:

```powershell
$env:LINK_CHECK_CONCURRENCY='25'
$env:LINK_CHECK_TIMEOUT_MS='8000'
node .\execution\audit_site.mjs
```

Optional smoke test:

```powershell
$env:LINK_CHECK_MAX='25'
node .\execution\audit_site.mjs
```

Google-only report:

```powershell
node .\execution\google_links_report.mjs
```

Resource preservation manifest:

```powershell
node .\execution\resource_preservation_manifest.mjs
```

## Workflow

1. Review `dashboard.html`.
2. Approve or reject cleanup candidates before deleting anything.
3. Fix links by bucket:
   - Google resources: replace, re-share, or intentionally hide.
   - Internal routes: fix source data or deploy routing.
   - Layer3: do not change without explicit approval.
   - Timeout/error: retry with browser/manual review before removal.
4. Use `resource-preservation-manifest.html` before removing Google resources. A local source/index file means the link was preserved in a workbook, CSV, or source document; it does not always mean the linked artifact content exists offline.
5. Rerun the audit and compare counts.
6. Commit each approved cleanup slice separately.

## Notes

The checker uses deterministic local extraction and HTTP/export probes. It does not use model calls for link validation. Google Docs/Sheets are checked through export URLs, which helps separate public resources from private or inaccessible ones. Google Drive account access can be spot-checked with the Google Drive connector when replacement sourcing is needed.
